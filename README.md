# Lebanese Restaurant

A modern and responsive Lebanese restaurant website template built with HTML5, CSS3, JavaScript, and Bootstrap 5.

This template features an elegant dark and gold design inspired by Lebanese cuisine and hospitality. It includes restaurant information, menu presentation, dish details, table reservations, customer reviews, and contact information.

## ✨ Features

* Modern and responsive restaurant design
* Full-width hero image carousel
* Lebanese cuisine and restaurant branding
* Featured menu items
* Menu and dish detail pages
* Restaurant story and culinary heritage section
* Table reservation form
* Customer reviews section
* Contact and location information
* Responsive navigation
* Interactive UI components
* Quick dish preview
* Mobile-friendly layout
* Dark and gold premium visual style

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap 5.3.3
* Bootstrap Icons
* Google Fonts

## 🚀 Getting Started

No build tools or server-side dependencies are required.

Clone the repository:

```bash
git clone https://github.com/walid-khalafi/lebanese-restaurant.git
```

Open the project folder and launch `index.html` in your browser.

For development, you can use **Visual Studio Code** with the **Live Server** extension.
